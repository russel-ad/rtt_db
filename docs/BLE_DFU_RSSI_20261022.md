# 扫描 RSSI 筛选（2026-10-22）

基于多设备 BLE DFU 页新增最低 RSSI 设置，固件工程未修改。

## 操作

设备扫描列表的名称/地址输入框下方，勾选“RSSI 过滤”，调整右侧 dBm 门限即可立即筛选本次扫描结果。

- 范围：-127～0 dBm，门限初始值 -70 dBm，默认不开启。
- 条件：只显示 `RSSI ≥ 门限` 的设备，门限本身也包含在内。未取得 RSSI 的设备在开启时隐藏。
- 例：设置 -70 dBm，-60 dBm 可见、-80 dBm 隐藏。负数越接近 0，信号越强。
- 与名称/地址筛选同时生效，无需重新扫描。RSSI 为最近一次扫描采集值，不是实时持续测量。
- 调整筛选不会清除之前的勾选，隐藏的勾选数量会显示在批量区。若只升级当前可见设备，先“清空勾选”，再“勾选可见设备”。
- 扫描、连接、升级等任务进行中，筛选控件暂时禁用。
