# 主机OTA升降级与同计数重装

2026-10-23按用户要求同步主机固件的新策略。752布局主机不再要求目标安装计数严格递增，允许更高、相同或更低的合法计数；0、0xFFFFFFFF及无效设备计数继续拒绝。从机的280/400KiB逻辑保持。

本次只改`FirmwarePackage.validate_device`的主机计数大小限制，保留包内HW/Model、布局、向量、长度、DAT/APP身份一致性、CRC32/SHA和ZIP检查。升级后仍确认自动断开/重连、显示版本、APP地址/长度和实际安装计数。正常发送中的CRC/偏移检查及最终提交保护保持。

## 使用方法

使用新文件：

`G:\rtt_db\dist\ble_dfu_host_scale_rollback_c3_20261023\rtt_t2_ble_dfu_host_scale_rssi_rollback_c3_20261023.exe`

1. 结束旧工具的任务并关闭旧版，打开上述EXE。
2. 选择“主机 SC200-D · 不断电OTA · 752 KiB”，首次只选一台，批量并发设1或取消批量模式。
3. 选择本轮交付包`C3_new/SC20X_HUB_V001_004.onmicro.zip`。不要选择整个测试合集ZIP或mlink的`.ota.bin`。
4. 如果设备当前显示版本也是V001_004，勾选“允许重装同版本”；这个选项按显示版本比较，独立于安装计数。
5. 按计数3→2→3→3发送，计数2对照包位于`C2_rollback_reference`，显示V001_005；每轮等待自动重连及版本/长度/计数确认，保存日志。

旧严格固件仍会在设备端拒绝同/低计数。首次装计数3包要求该设备当前计数<3；上位机开放规则不能替旧设备绕过其限制。低计数目标APP自身也应包含新策略，才能继续双向升级。

EXE保留原RTT/串口、主从机分区、RSSI筛选、批量、取消与进度功能。原portable版和其他已有EXE保留，不覆盖。
