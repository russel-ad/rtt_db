# 升级进度条显示修复（2026-10-22）

旧版将设备设置、固件设置、批量结果、总进度条及日志放进同一个滚动页面。内容高度超过窗口后，总进度条出现在可视区域下方；升级数据仍正常更新，例如截图中的 54.1%。

本次修改 PC 界面布局，保留 RSSI、批量队列和原有单设备 DFU 协议流程：

- 总进度、速度、状态、开始/停止按钮固定在页面底部，独立于中间滚动内容。
- 开始单设备或批量升级时自动收起设备/固件设置，优先展示任务进度和日志。
- 页面右上角“显示设备 / 固件设置”可随时展开设置。操作仍遵守原任务期间的禁用规则。
- 每台设备的进度列增加图形进度条，同时显示百分比。
- 传输达到 100% 后仍需等待提交、重启和目标版本确认，只有确认成功才显示“升级成功”。

## 使用

待原有升级任务完成后，启动 `rtt_t2_ble_dfu_batch_progress.exe`。保留之前的扫描/RSSI 筛选、固件选择、并发 1～4 台及结果导出流程。

`firmware` 目录沿用此前 V001_004 测试 OTA ZIP，没有重新编译或修改固件。
