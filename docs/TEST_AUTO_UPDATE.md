# 上位机自动更新测试：2.10.0 → 2.10.1

适用 Windows x64。此包用于在另一台电脑验证上位机程序自动更新，无需连接蓝牙设备。

1. 下载 `RTTTool_UpdateTest_2.10.0_to_2.10.1.zip`，右键选择“全部解压”。
2. 运行解压目录顶层的 `RTTTool_UpdateTest.exe`。首次窗口标题显示 **v2.10.0**。
3. 保持联网，观察窗口底部“上位机更新”状态。也可点击“更新 → 检查上位机更新”。
4. 出现“新版 2.10.1 已下载”后，可点击“更新 → 重启并更新”，或保持没有设备连接、
   没有操作的空闲状态60秒，等待自动重启。也可以正常退出后再次启动这个测试 EXE。
5. 重启后窗口标题显示 **v2.10.1**，底部显示当前版本已是可用版本，即完成测试。

请通过测试启动器进入；`app` 子目录中的 EXE 用于内部启动。
下载受当前网络影响，失败后会保留旧版并在运行期间每五分钟重试，也可以主动检查。
设备升级、连接、RTT/串口连接或对话框未结束时，程序会等待空闲再切换版本。

## 隔离范围

- 测试更新清单：`https://github.com/russel-ad/rtt_db/releases/download/v2.10.1-test/latest.json`。
- 测试更新、配置和日志：`%LOCALAPPDATA%/RTTToolUpdateTest/v2.10.1/`。
- 正式版更新源及 `%LOCALAPPDATA%/RTTTool/` 数据继续独立使用。
- 本包初始程序来自已公开校验的 v2.10.0，v2.10.1 是从隔离源码快照重新构建的测试目标。
- 两版均保留现有工作台功能；这次测试验证的是上位机程序更新，无需刷设备固件。
- 更新包沿用正式发布公钥，需通过 Ed25519 签名、大小及 SHA256 校验。

此 Release 标记为 Pre-release，不更改正式版的 Latest 指向。
普通 v2.10.0 正式启动器继续检查正式更新；本测试入口专门用于验证这次升级。

如未成功，请提供窗口底部的更新状态，以及上述测试目录下 `updates/last-error.json`
是否存在。请勿将账号缓存、工厂密钥或设备认证资料提交到公开仓库。
