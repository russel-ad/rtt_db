## 支持的三个分区

| 界面选项 | 执行地址 | 镜像大小上限 |
| --- | --- | --- |
| 从机 · 原布局 | 0x00404000 | 280 KiB |
| 从机 · 已迁移布局 | 0x00404000 | 400 KiB |
| 主机 SC200-D · 不断电OTA | 0x00409000 | 752 KiB |

主机配置独立解析 DAT 安装计数，核对编译身份、SC200-D / DFT-SC20X-HUB 标记、向量、256 字节尾部、CRC32 和 SHA-256；不能通过单纯放大从机长度限制替代。设备须报告主机地址、长度和有效计数，包计数须严格大于设备计数。“允许重装同版本”不能绕过计数要求。

升级后同时核对显示版本、实际 APP 地址/长度与安装计数，不能仅凭显示版本判成功。主机/从机误选分区会在传输前拒绝。

## 本次主机测试方法

1. 原有升级任务完成后，运行 `rtt_t2_ble_dfu_host_scale_rssi_portable.exe`。
2. 在“蓝牙 DFU 升级”中选“主机 SC200-D · 不断电OTA · 752 KiB”。
3. 选择 `firmware/SC20X_HUB_V001_005.onmicro.zip`，确认 V001_005、SC200-D、安装计数 2。
4. 首次只勾选一台符合原不断电 OTA 分支布局的主机，并发设为 1；按蓝牙地址核对，手机先释放连接。
5. 开始升级，待传输、提交、重启和版本/长度/计数确认结束。

主机固件沿用此前隔离构建的同一份文件，没有重新编译或修改：

- 版本 V001_005，安装计数 2，APP 含尾部共 619748 字节。
- ZIP SHA-256：`adf4a6da27744cf8e5d88c2ce9697fad303524aeead91e5ddc337faf2d988169`。
- BIN SHA-256：`3f78dc62ad8cfb51023dc9010cb2d2f1474a40af444afe24c5d2e5371bf1fcaa`。
- 用于原安装计数 1 的设备；计数已达 2 或以上时拒绝，不能反复使用本包替代更高计数的新版本。
- 仅升级 APP，字体图片资源不随 DFU 更新；`resource_separate/resource.bin` 沿用原交付文件，不能当作 DFU ZIP 选择。

保留 RSSI / 名称 / 地址筛选、并发 1～4 台、每台图形进度条、固定底部总进度/停止按钮、提交保护与结果导出。BLE / 串口启动不需要 J-Link DLL；仅在明确点击 RTT 连接时加载，缺失时提示而不退出。
