# 旧版上位机更新下载修复

适用场景：v2.10.0 已提示“正在后台下载上位机”，随后显示“更新暂不可用”，无法完成首次升级。

1. 等设备任务结束后，退出原上位机。
2. 下载并完整解压 `RTTTool_UpdateRepair_2.10.3.zip`。保留解压目录中的 `_internal`。
3. 运行 `RTTTool_UpdateRepair.exe`，选择原上位机文件夹顶层的 `RTTTool.exe`。
4. 点击“下载并准备更新”。界面显示实时百分比、已下载/总大小及速度；网络中断会自动重试，保留下载进度供续传。
5. 准备完成后，点击“启动上位机”。原启动器安装新版并执行启动检查，成功后标题显示新版本。

修复工具使用内置正式更新地址及发布公钥，验证 Ed25519 签名、大小和 SHA256。它只准备更新包，版本安装和启动回退仍由原启动器完成，不连接蓝牙或操作设备固件。

若网络持续无法访问更新服务器，工具会保留部分文件。恢复联网后，再次点击“下载并准备更新”继续。
错误记录位于 `%LOCALAPPDATA%\RTTTool\updates\last-repair-error.json`；请仅提供此诊断文件中的错误文本，不发送账号缓存或工厂资料。

从 v2.10.3 起，上位机自带相同的下载续传逻辑，后续正常使用程序内更新即可。
